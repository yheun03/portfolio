성장 과정

실전 경험으로 성장한 웹 퍼블리셔

고등학교 시절 HTML, CSS, JavaScript를 배우며 웹 개발을 시작했고, 동아리와 메이커톤, 팀 프로젝트를 통해 직접 결과물을 만드는 경험을 쌓았습니다. 이후 실무에서는 기업 시스템과 자사 솔루션 프로젝트를 수행하며 사용자 관점과 개발 구조를 함께 고려하는 퍼블리셔로 성장했습니다.

직무 강점

디자인과 개발 사이를 연결하는 실행력

저의 강점은 화면을 구현하는 데서 끝나지 않고, 유지보수 가능한 구조로 정리하는 데 있습니다. SCSS 컴포넌트화, 공통 UI 정리, CMS 커스터마이징을 통해 반복 작업을 줄이고 개발자가 안정적으로 연동할 수 있는 화면을 만들었습니다.

성격 및 협업 방식

꼼꼼함과 공유 중심의 협업 방식

화면 간격, 폰트, 반응형 흐름처럼 작은 차이가 사용자 경험을 좌우한다고 생각합니다. 그래서 구현 과정에서 디자인 의도와 개발 제약을 함께 확인합니다. 협업에서는 먼저 정리하고 공유하는 방식을 선호하며, 가이드와 예시를 만들어 팀원들이 같은 기준으로 작업할 수 있도록 돕습니다.

가치관 및 포부

퍼블리싱을 기반으로 프론트엔드까지 확장

앞으로는 HTML, SCSS 기반의 강점을 유지하면서 Vue 3, API 연동, 상태 관리, 라우팅, 다국어 처리 등 프론트엔드 영역을 더 깊게 확장하고자 합니다. 디자인 의도를 정확히 구현하는 퍼블리셔를 넘어, 서비스 구조와 사용자 경험을 함께 고민하는 프론트엔드 개발자로 성장하겠습니다.
