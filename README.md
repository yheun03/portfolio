# 은영환 포트폴리오

웹 퍼블리셔 은영환의 경력과 프로젝트를 소개하는 개인 포트폴리오입니다.

**사이트:** [https://yheun03.github.io/](https://yheun03.github.io/)

## About Me

HTML과 SCSS를 중심으로 웹 UI를 구현해 온 7년차 웹 퍼블리셔입니다. 기업 홈페이지, 스마트팩토리·물류 시스템, 자사 솔루션 등 다양한 프로젝트에서 운영, 신규 구축, 내부 리뉴얼을 경험했습니다.

화면의 목적과 콘텐츠 우선순위를 이해하고, 읽기 쉬운 마크업과 유지보수 가능한 스타일 구조를 만드는 일을 중요하게 생각합니다. 현재는 Vue 3를 기반으로 컴포넌트와 상태 흐름을 설계하며 프론트엔드 개발 역량을 확장하고 있습니다.

## Portfolio

- **Home** — 소개, 대표 프로젝트, 작업 방식과 기술 역량
- **Projects** — 기업 홈페이지와 업무 시스템 등 실무 프로젝트
- **Personal** — 직접 기획하고 구현한 개인 프로젝트
- **Journey** — 경력과 역할, 주요 경험을 시간순으로 정리한 이력
- **Highlights** — 수상, 자격, 활동과 주요 성과

프로젝트 상세 페이지에서는 작업 배경, 담당 역할, 사용 기술과 실제 화면을 확인할 수 있습니다.

## Project

Nuxt 3와 Vue 3를 기반으로 제작한 정적 포트폴리오 사이트입니다. 콘텐츠는 한국어와 영어를 지원하며, 프로젝트 데이터와 화면 컴포넌트를 분리해 관리합니다.

```bash
npm install
npm run dev
```

```bash
npm run build
npm run deploy
```

이력서는 [`public/files/Resume.pdf`](public/files/Resume.pdf)에서 확인할 수 있으며, 2025년 포트폴리오는 `public/ver.2025/`에 보관되어 있습니다.
